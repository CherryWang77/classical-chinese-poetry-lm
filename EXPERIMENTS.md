# Experiment record

All main runs used the edited 5 MiB Song-ci corpus, context length 256, AdamW, learning rate `3e-4`, dropout `0.1`, and the fixed prompt:

```text
气和玉烛，睿化著鸿明。
缇管一阳生。
```

The D384/H4 value above is calculated directly from the merged CSV. Earlier narrative notes selected step 5800 (`4.026370`), but the preserved 0-5000 artifact contains a lower step-5000 value (`4.004561`). The CSV is treated as the authoritative artifact until the report is updated.

## Evaluation provenance

The preserved historical runs evaluated five random validation batches every 200 steps. Their validation split was fixed, but the sampled validation windows were not shared explicitly across experiment processes. The refactored trainer corrects this by precomputing validation windows from `eval_seed` and using the same evaluation batch size in every configuration. Consequently:

- historical CSV values remain the evidence for the submitted report;
- future reruns are more strictly controlled;
- exact equality between historical and refactored validation values is not expected, even with the same model hyperparameters.

## Checkpoint and sample selection

The repository intentionally does not track `.pt` files. Checkpoints are large, reproducible training artifacts and are ignored by Git. Curated generated samples are retained because they support qualitative comparison without requiring the model weights.

The two primary samples discussed in the report are:

- `results/samples/six_layer_bs32_dim256_heads8_step_10000.txt` - strongest balanced model;
- `results/samples/six_layer_bs32_dim384_heads8_step_5000.txt` - strongest peak model.

Later samples remain available to demonstrate qualitative narrowing alongside increasing validation loss.

## Structural comparison of the two report samples

`results/generation_structure_comparison.json` was generated by `scripts/analyse_generation.py`. It provides a reproducible quantitative complement to close reading:

| Text | Mean characters per line (punctuation removed) | Punctuation rate | Line-length total variation from corpus |
|---|---:|---:|---:|
| Edited 5 MiB training corpus | 8.9089 | 0.1706 | 0.0000 |
| D256/H8, step 10000 | 8.9444 | 0.1910 | 0.3224 |
| D384/H8, step 5000 | 8.1500 | 0.1684 | 0.3221 |

Both selected outputs therefore reproduce the corpus's typical local line-length scale and punctuation density approximately, while their non-zero distribution distance confirms that they do not reconstruct the corpus form exactly. Because each saved generation is short, these statistics are descriptive evidence rather than a population-level significance test.
